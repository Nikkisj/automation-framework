# automation-framework

## Project Overview
Selenium Hybrid Automation Framework using Java, TestNG, Cucumber, Maven and Jenkins.

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Cucumber
- Maven
- Jenkins
- Extent Reports

## Framework Features
- Page Object Model (POM)
- Hybrid Framework
- Cucumber BDD
- Modulewise Execution
- Screenshot Capture
- Reporting

## Modules Covered
1. Login
2. Registration
3. Search Product
4. Cart
5. Checkout
6. Logout

## Run Framework
mvn clean test

## Reports
- test-output/index.html
- reports/ExtentReport.html
- target/cucumber-report.html
